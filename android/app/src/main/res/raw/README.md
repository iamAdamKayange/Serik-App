# Android Notification Sounds

Place MP3 sound files here for Android notification sounds:

Required files (without .mp3 extension):
- notification_general
- notification_payment  
- notification_verification
- notification_verification_rejected
- notification_verification_reminder
- notification_maintenance
- notification_alert
- notification_house

Example: notification_general.mp3 → notification_general

This directory is used by Flutter's RawResourceAndroidNotificationSound
for custom notification sounds on Android.
